# radio-dev
 
Local Radio service with AI generated podcasts and news in French !

---

## Requirements

| Tool | Role |
|------|------|
| Docker | Run the service |
| Docker Compose | same as above |


## Setup

```bash
docker compose up -d
```

## Usage

visit this URL : http://localhost:8080/

> If you plan on publishing this on the internet as a website, CHANGE THE PASSWORDS in `docker-compose.yml` and `icecast.xml` !

## Troubleshoting

Q: No music ??

A: You must put your own .mp3 files in the music subfolder

Q: generator not working

A: remove the .venv inside the generator (it MUST be generated by Docker)
